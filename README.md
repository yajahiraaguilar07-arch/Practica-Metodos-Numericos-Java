Práctica: Método de Gauss-Jordan en Java

Estudiante: Yajahira Aguilar
Asignatura: Métodos Numéricos
Tema: Resolución de sistemas de ecuaciones lineales mediante el método de Gauss-Jordan.

Descripción

Este proyecto tiene como objetivo implementar el método de Gauss-Jordan en Java para resolver sistemas de ecuaciones lineales mediante operaciones elementales sobre matrices.

Objetivo

Desarrollar un programa que permita ingresar una matriz aumentada, transformar la matriz hasta obtener la forma escalonada reducida y calcular las soluciones del sistema de ecuaciones.

Funcionamiento

1. Solicitar el tamaño del sistema de ecuaciones.
2. Leer los coeficientes y los términos independientes.
3. Formar la matriz aumentada.
4. Aplicar el método de Gauss-Jordan.
5. Mostrar la matriz resultante y las soluciones, cuando existan.

Tecnologías utilizadas

- Lenguaje de programación Java.
- GitHub para almacenar y documentar el código fuente.

Ejecución

El programa se ejecutará desde una terminal o un entorno de desarrollo compatible con Java, una vez agregados los archivos fuente.

Estructura del proyecto

Los archivos fuente se organizarán en clases para la entrada de datos, la eliminación gaussiana, el método de Gauss-Jordan y la ejecución principal.

Conclusión

Esta práctica permite comprender cómo se utilizan las operaciones elementales de matrices para resolver sistemas de ecuaciones lineales mediante un método numérico.
